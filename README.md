# 🍢 미니 떡볶이 타이쿤 3D

벚꽃 흩날리는 마을 골목길에서 나만의 작은 떡볶이 가게를 운영하는 **파스텔톤 3D 미니어처 타이쿤 게임**입니다.
Three.js 하나로 만든 **단일 HTML 파일 게임**이라 서버 없이 어디서든 돌아갑니다.

## 🎮 실행 방법

- **가장 쉬운 방법**: [index3d.html](index3d.html) 파일을 브라우저로 열기 (인터넷 연결 필요 — Three.js CDN 사용)
- **로컬 서버로 열기**: `npm start` 또는 `python -m http.server 8123` → `http://localhost:8123/index3d.html`

## ✨ 주요 기능

- 🏪 창업 튜토리얼 & 가게 이름 짓기 (3D 간판에 실시간 반영)
- 🪑 테이블+의자 세트 가구 3종 구매/90도 회전 배치 (초록/빨강 격자 가이드)
- 🧑‍🤝‍🧑 의자 수에 비례해 몰려오는 단체 손님 + 문 앞 웨이팅 대기열
- 📖 메뉴 도감 연구 (손님마다 랜덤 주문, 메뉴별 가격 정산)
- 💰 자석처럼 빨려오는 동전 자동 수거
- 🌸 벚꽃나무 + 흩날리는 꽃잎 파티클 + 파스텔 그라데이션 하늘 + 미니어처 마을 배경
- 📱 모바일 최적화: 세로형 화면, 터치 드래그 이동 / 핀치 줌 / 두 손가락 비틀기 회전
- 💾 localStorage 자동 저장 (골드·가구·메뉴·가게 이름)
